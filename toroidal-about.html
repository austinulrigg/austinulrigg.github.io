About and cite

The database

This is a growing database of toroidal obstructions. It began with the three collections in Wendy Myrvold’s torus obstruction database. Contributions of additional graphs, references, and corrections are welcome. The database does not claim to contain every toroidal obstruction.

Attribution and citation

Each graph record identifies its sources and discovery credit. Please cite those original sources when using a graph, together with its TO identifier, release date, and database address. Inclusion in this database does not transfer discovery credit to its maintainers.

Graphs imported from Myrvold’s collection retain their original file and line references. Their obstruction claims are source-reported. New contributions will carry their own attribution and verification records.

Reference for the initial collections

Wendy Myrvold and Jennifer Woodcock. A large set of torus obstructions and how they were discovered. The Electronic Journal of Combinatorics 25(1), P1.16 (2018).

Graph parameters

Vertex connectivity is the minimum number of vertices whose removal disconnects a connected noncomplete graph. Edge connectivity is the minimum number of edges whose removal disconnects it. Both values are zero for disconnected graphs. The vertex connectivity of a complete graph on n vertices is n − 1. Missing values are shown as “Unknown” and sort last.

Vertex and edge counts, degrees, connected components, bipartiteness, regularity, and both connectivities are computed with igraph 1.0.0. Isomorphic records are matched using Bliss canonical labeling. The graph6 data and drawings retain the first source record’s vertex labels. An exact graph6 search uses those labels.

Drawings and downloads

The surface button requests an embedding from Alexander Metzger’s genus solver. A returned surface is an embedding witness. It does not by itself verify non-toroidality or minimality. Some requests may time out or fail to produce a drawing.

Downloads support graph6, upper triangular form, adjacency lists, and adjacency matrices. Upper triangular records begin with the vertex count, followed by entries in row order above the diagonal. Lists and matrices use vertices numbered from 0 to n − 1. Multiple list or matrix records are separated by a blank line and identified by a comment line.

Additions and corrections

Submit a graph or correction with its source and attribution. Submissions enter a private queue. They are added to a later release only after verification and citation review.
